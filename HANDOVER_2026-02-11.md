## Technical Notes for Next Session

### How the Grid Works

1. **Entry Point:** `MobileUI.handleMapTap()` calls `actionGrid.showForTile(tile, game, attackRatio)`
2. **Category Detection:** `determineTileCategory()` returns one of 9 categories based on:
   - `game.owner(tile)` → is it mine/enemy/neutral?
   - `game.isLand(tile)` → land or water?
   - `game.isShoreline(tile)` → shore (land + adjacent water)?
   - `myPlayer.actions(tile)` → can I attack? (async)
3. **Action Generation:** `getActionsForCategory()` calls specific method like `getOwnLandActions()`
4. **Rendering:** Lit renders grid with `html` template, high-priority items get `grid-column: span 2`
5. **Event Flow:** User taps action → `action-selected` event → `MobileUI.handleActionSelected()` → routes to existing event emitters

### Visibility Bug Resolution (for reference)

**Root Cause:** The same tap that opened the grid was also triggering backdrop click, closing it instantly.

**Fix:** Added `lastOpenedTime` timestamp + 300ms guard in `handleBackdropClick()`:

```typescript
const timeSinceOpen = Date.now() - this.lastOpenedTime;
if (timeSinceOpen < 300) return; // Ignore backdrop click if just opened
```

### Spawn Phase vs Normal Gameplay

**Spawn Phase:**

- `handleMapTap()` checks `game.inSpawnPhase()`
- If true: emit `SendSpawnIntentEvent(tile)` immediately
- Grid is NOT shown during spawn phase

**Normal Gameplay:**

- `handleMapTap()` calls `actionGrid.showForTile()`
- Grid appears with context-appropriate actions
